Cinevo – Movie Booking System

An online movie ticket booking website built with PHP and MySQL. Users can register, log in, reset a forgotten password by email, browse and filter movies (all, now showing, upcoming), open a movie details page with reviews, choose seats for a show and see their bookings. A full admin panel lets the admin manage movies, categories, theaters, shows, seat classes and pricing, users and reviews, and view revenue reports.

Campus Coin – Student Finance Tracker

A student expense management web app built with Laravel and MySQL. Students can sign up with email OTP verification, record daily expenses and income, set category budgets with alerts, schedule recurring transactions, get monthly insights and smart saving tips, and export reports as PDF. A separate admin panel manages users, categories and announcements, and shows analytics.
